# OCR language models

`chi_tra.traineddata.gz` is used only for a second reading of an uncertain
payment-method field. It is not used to infer a channel from the bill's merchant,
discount wording, or other page content.

Source: https://cdn.jsdelivr.net/npm/@tesseract.js-data/chi_tra/4.0.0_best_int/chi_tra.traineddata.gz

Upstream language data: https://github.com/tesseract-ocr/tessdata_best

unchanged; the gzip wrapper was regenerated with a deterministic timestamp.
