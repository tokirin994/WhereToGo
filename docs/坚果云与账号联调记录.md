| --- | --- |
| 未登录读取坚果云配置 | 返回 401 |
| 公开注册及 PKCE 授权码登录 | 成功，访问令牌包含有效 sub |

集成脚本将以上行为汇总为 13 个 PASS 项。登录和注册页面返回 200，继承样式与自定义样式资源均返回 200，返回门户链接及注册表单存在。

测试只使用人工生成的一笔 12.34 元流水，不上传用户原账本，不覆盖已有云快照。提供的坚果云密码仅经测试进程内存和凭证加密接口传递，没有写入脚本、报告或日志；测试结束后数据库中的临时加密凭证也已删除。没有将此账号自动绑定到日常使用的 admin 账号。

## 复现

先启动本机服务，再运行以下命令，按提示输入坚果云邮箱和应用密码：

```powershell
./scripts/test-nutstore.ps1
```

需要当前 Windows 用户可解密本机身份服务的 bootstrap 凭据。脚本通过真实注册表单建立两个临时用户，用标准授权码 + PKCE 流程获取令牌，不开启 SPA 的密码直接授权。它会向提供的坚果云空间写入一个独立临时文件，并在 finally 中清理；不会删除 SmartLedger 目录或其他文件。

## 本次修正

最初的集成运行发现两个 SPA 客户端的默认 scope 列表遗漏 `basic`，导致 access token 缺少 API 必需的 subject。已在 realm 模板和本机配置迁移中修正，并用真实注册及 API 调用复测通过。
