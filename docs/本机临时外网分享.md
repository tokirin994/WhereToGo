# 本机临时外网分享

这套脚本用于短时间邀请朋友体验。Windows 电脑运行门户、旅行、记账、统一登录和 PostgreSQL，通过 Cloudflare Quick Tunnel 提供随机 HTTPS 链接。无需域名，也无需在路由器上映射端口。

## 已有服务与数据

- 分享期间停止原来的本地开发服务，以减少内存占用。
- 每次新分享创建独立的旅行、记账、登录数据库和登录 realm；不会复制你的原始账本、旅行数据或坚果云凭据。
- 默认创建 `host` 和 `guest1`～`guest3`，均无系统管理员权限。给每位朋友一个不同账号。
- 门户可公开浏览；打开应用时需要登录。体验环境关闭自助注册，接口仅允许本次创建的账号。
- 数据库、Java 服务和网关只监听本机。公共网关不转发 Keycloak 管理后台、master realm、数据库或诊断接口。
- 默认八小时后网关拒绝业务访问。电脑休眠、关机、退出系统或隧道断开也会中断服务。

## 开始分享

在项目根目录打开 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-share.ps1
```

脚本使用本机 `D:\Application` 已安装的 Node.js、Java 8、Java 21、Maven、PostgreSQL 16 和 Keycloak。Cloudflared 固定版本安装在 `D:\Application\cloudflared`，首次下载会核验 SHA-256。前端、后端按生产方式构建，运行文件写入独立的分享目录。

启动需要几分钟。看到 `Ready: https://……trycloudflare.com` 后，把该地址发给朋友。旅行和记账入口都在门户中。每次重新开始分享地址都会变化。

可设置分享时长和朋友数量：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-share.ps1 -Hours 8 -GuestCount 3
```

时长支持 1～24 小时，朋友账号数量支持 1～10。不要同时运行 `start-local.ps1` 和分享启动脚本。

### 只开放记账

新建一轮只含记账与统一登录的分享：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-share.ps1 -LedgerOnly
```

将正在运行的完整分享切换成只开放记账，保留本轮账号、数据、地址和到期时间：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\use-ledger-share.ps1
```

切换脚本先完成新前端构建，再切换网关并停止本轮旅行 API。根地址自动转到 `/ledger/`；门户、旅行页面及旅行 API 不再对外开放。记账页面隐藏门户和旅行入口，账号管理进入本轮登录服务的账号中心。

恢复当前会话的门户、旅游和记账：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\use-full-share.ps1
```

账号、数据、地址及到期时间保留。免费固定子域名的完整部署目标见 [完整服务方案](完整服务免费固定子域名-TailscaleFunnel.md)。

### 固定链接与 Cloudflare 注册

`trycloudflare.com` 地址属于 Quick Tunnel，无法通过注册账号把当前地址永久保留。固定 Cloudflare 公网入口需要账号、本人可控制并托管在 Cloudflare 的域名，以及正式 Tunnel。仅购买域名不会让本机服务自动常驻；仍需设置启动、恢复和备份。

可以使用自己的 QQ 邮箱在 [Cloudflare 官方注册页](https://dash.cloudflare.com/sign-up) 注册，设置单独的新密码，并在邮箱中完成验证。不需要把邮箱密码发给开发者。注册规则见 [官方账号创建说明](https://developers.cloudflare.com/fundamentals/account/create-account/)，固定 Tunnel 前提见 [官方部署说明](https://developers.cloudflare.com/tunnel/get-started/)。

完成注册后提供要使用的域名，再配置正式隧道、登录回调、两个应用的公开地址、开机启动和移除体验到期限制。没有域名时，可另选提供固定免费子域名的服务；不会把当前临时地址描述成永久入口。

## 查看体验账号密码

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\show-share-accounts.ps1 -Username guest1
```

省略 `-Username` 可以查看本次所有体验账号。只把相应朋友的账号密码交给该朋友；账号不是原来本地系统中的账号。`host` 留给自己使用。

## 关闭分享并恢复本地开发服务

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-share.ps1 -RestoreLocal
```

只关闭分享而不启动原本地服务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-share.ps1
```

八小时到期只关闭网关访问，不会自动终止 Java 和 PostgreSQL。体验结束后运行停止脚本释放服务资源。停止脚本保留分享数据；再次开始会创建全新的体验数据环境，不会自动迁移上一轮的数据。

## 文件和凭据

分享状态目录：`D:\Application\WhereToGo\share`。`current.txt` 指向当前会话，`sessions\<时间戳>` 存放本次构建、日志和状态。

- 临时账号和数据库密码保存在 `accounts.clixml`，使用当前 Windows 用户的 DPAPI 加密；不会写进 Git。
- 坚果云服务端凭据使用独立 AES-256-GCM 密钥加密。密钥文件通过 Windows ACL 限制为当前用户与 SYSTEM 可读，不与原本地密钥混用。
- 创建登录账号所需的明文导入文件位于受保护目录，登录服务成功启动后删除。
- 状态、密钥、数据库目录需要一起保护；拥有当前 Windows 用户权限的人可以读取运行所需密钥。
- 记账应用仍有浏览器本地缓存。共享电脑上使用后应退出账号；外网体验建议只填测试数据。

## 启动失败

查看当前会话的 `logs` 目录，不要将包含个人信息的完整日志公开。关闭失败的会话并恢复本地服务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-share.ps1 -RestoreLocal
```

仅当失败发生在前后端构建完成以后、且登录及两个 API 都尚未运行时，可修复原因后使用 `start-share.ps1 -Resume` 继续已有隧道。其他情况请先停止，再重新开始。

## 使用范围

适合少量朋友临时体验。速度取决于本机上行带宽和 Cloudflare 隧道线路；Quick Tunnel 没有可用性承诺。AI 等外部服务仍需要相应服务配置，本脚本不会自动开通或复制付费密钥。后续正式部署可继续使用独立的部署方案文档。
