# 账号工作台与页面恢复

## 页面入口

`/account/` 默认进入账号总览。保持原有深链接：`?tab=profile`、`?tab=security`、`?tab=providers`、`?tab=ledger`。账号总览使用 `?tab=overview`。

| 区域 | 操作 |
| --- | --- |
| 我的应用 | 根据应用注册表显示旅行、记账和以后启用的应用；直接打开应用并衔接已有 SSO 会话 |
| 状态卡片 | 从真实账号接口展示设备数量、个人服务配置数量、坚果云配置状态；点击进入对应设置 |
| 常用设置 | 进入资料、AI、地图及记账配置；地图快捷入口自动选中高德服务 |
| 门户外观 | 浅色、夜间、跟随系统，立即生效，保存在当前浏览器 |
| 资料与邮箱 | 修改称呼，换绑邮箱；用户名保持只读 |
| 登录安全 | 修改密码、查看设备、结束其他会话；敏感账号修改仍由身份服务验证 |
| AI 与地图 Key | 加密保存、测试、切换、删除个人配置，兼容参数默认折叠 |
| 记账与云同步 | 与记账应用操作同一份坚果云配置，直达账本同步设置 |

设备、资料、服务配置读取失败不会隐藏应用入口。加载中显示等待状态，失败后按分区提示并可重试。设备列表接口失败不会阻止已加载资料的修改。

## 白屏防护

`packages/platform` 提供三个共享组件/函数：

- `ApplicationBoundary.vue`：捕获子组件初始化或渲染异常，以及 Vite 资源预加载错误。显示恢复操作，不将原始错误或响应内容展示给用户。
- `PageState.vue`：统一等待、失败提示、返回门户和手动重新加载按钮，适配浅色、夜间和手机布局。
- `asyncPage()`：页面组件延迟加载超过 150 ms 显示等待界面，20 秒后若仍未完成则显示恢复提示。

三个 HTML 入口在脚本执行前已有等待文字和禁用 JavaScript 的说明。门户、旅游和记账在根节点使用异常边界；主要动态页面使用同一套等待与恢复机制。

恢复组件不清空 IndexedDB、会话存储、用户数据或数据库，不自动刷新形成循环。如果用户正编辑未保存内容，手动重新加载仍会丢失该页面的未保存输入，因此先保存可操作的内容。

## 数据格式与检查

- 账号接口明确请求 JSON。返回登录网页或 SPA HTML 时，显示可理解的错误，不只判断 HTTP 200。
- 资料和设备数据先验证形状再显示；设备日期兼容 Unix 秒、毫秒、数字字符串和 ISO 字符串，非法日期显示 `—`。
- 自动回归覆盖应用入口、设置跳转、外观切换、失败恢复、部分接口不可用、异步等待、非法响应及原有凭据管理操作。
- `scripts/test-sso.mjs` 检查真实身份会话、资料、设备和应用配置的 JSON 格式、归属和关键字段。测试不等同于浏览器视觉验收。

本次没有改变账本数据模型、旅行数据模型或数据库部署数量。外部 AI、地图和坚果云是否真正连通，仍依赖当前账号保存的有效配置与供应商服务状态。
