# 记账统计与手机布局

## 统一计算规则

实现参考 `SmartLedger-reference` 原版 App 中的 `LocalAnalytics.selfShareAmount`、`TransactionLedgerLink.selfShareAmount` 和账本统计逻辑。

- 无分摊：计整笔金额。
- 平均分摊：本人参与时计整笔金额除以参与人数；本人未参与时计零。
- 比例 / 固定金额：计本人配置的份额。网页比例单位为百分数，兼容原 App 关联配置中的小数比例。
- 不计统计：流水仍可查看和编辑，统计金额为零。支持流水整体和单个账本的统计开关。
- 同一流水关联多个账本：全局只计一次，与原 App 一致选用 ID 排序最前的已关联账本配置；当前账本内使用该账本的独立配置。
- 抵扣保留为独立的关联收入；支出、收入分别汇总，结余为收入减支出。抵扣保留分摊身份与配置，来源流水修改后同步其分摊配置。
- 分期按每期实际日期纳入相应周期。时间范围统一为开始日包含、结束边界不包含，本月覆盖整月。
- 优惠、溢价为独立附加指标，统计有效支出的原始优惠 / 溢价字段，不再次从已支付金额中加减。

核心计算集中于 `ledger.ts` 的 `transactionShareAmount`、`transactionInStatistics` 和 `statisticsSummary`。首页、分类图、趋势、流水筛选结果、按日汇总、日历、账本卡片、账本详情、预算和导出报告共用这些函数。

流水主金额继续显示整笔订单金额，分摊时另列“本人”金额，排除项标明“不计统计”。统计区会说明本人份额，避免与订单总金额混淆。不同的日期、分类或账本筛选范围本身会产生不同的汇总。

## 图表交互

分类统计支持环图 / 柱图、占比 / 金额分别切换。点击有下级分类的行可继续查看下一层，面包屑支持返回；也可通过分类选择器直接选定范围。直接记录于父分类的订单展示为“本级直接记账”，无分类订单保留在“未分类”，不将可选择的大类合并为“其他”。各级比例均以当前范围的本人支出合计为分母。

环图可以通过点击或键盘选择扇区。趋势支持日 / 周 / 月粒度，点击柱形显示金额；需要横向浏览的趋势只在图表内部滚动。默认本周看日、本月看周、本年看月，周按周一分界。

## 布局修复

流水与账本详情使用 `minmax(0,1fr)` 网格列，并明确允许内容收缩。长标题省略、日期和筛选输入受容器约束，局部滚动不会扩大整页。手机上的搜索、日期输入字体至少 16px，避免 Safari 自动放大输入框。

## 回归方式

`npm run test --workspace @personal/ledger` 覆盖原有测试和统计 / 分类交互回归。浏览器回归使用独立合成账本，在 WebKit 下检查手机、平板、桌面尺寸的页面宽度、分类逐层查看、图表切换和收支一致性；不写入真实用户账目。
