# 记账分类图标

## 显示方式

分类图标由 `apps/ledger/src/categoryIcons.ts` 统一解析，`CategoryIcon.vue` 绘制本地 SVG。分类管理、分类选择、流水、概览、OCR 与抵扣编辑使用相同的组件，不依赖在线字体或外部图片服务。

原生应用快照使用 SF Symbols 名称，例如 `banknote.fill`、`bicycle`、`drop.fill`。旧版网页映射不完整，未匹配的图标显示为 `◈`，在小尺寸下看起来像圆点。现在兼容这些名称及常见装饰后缀，提供 63 种可选择的图标。

解析顺序：

1. 明确的图标 ID、原生图标名称和别名。
2. 已收录的 Emoji 对应的 SVG；其他有效的自定义 Emoji 继续保留。
3. 无法匹配时，依据分类名称选择语义接近的图标。
4. 无法判断时，显示清晰的标签或收入箭头，不再显示点状占位符。

## 编辑与数据兼容

编辑分类时可以搜索图标、按分组浏览，预览使用当前分类颜色。图标面板适配手机宽度与深浅色主题。

兼容映射只作用于显示，不会批量重写已有分类的 `icon`、分类 ID、流水关联或云端快照。只有用户明确选择并保存另一个图标，才修改该分类的图标字段。

## 扩展

增加图标时，在 `categoryIconOptions` 登记 ID、名称、分组与文本替代；在 `CategoryIcon.vue` 的 `components` 中绑定图形。如需兼容其他来源，在别名表中加入其名称。`CategoryIconId` 类型会约束图形映射必须完整。
