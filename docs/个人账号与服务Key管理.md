# 个人账号与服务 Key 管理

入口：<https://personal-45-205-23-125.sslip.io/account/>。门户、旅行及记账的应用菜单均可进入。

门户已移除应用卡片上方的注册宣传卡，右上角及统一登录页仍保留注册入口。

## 页面功能

| 页签 | 功能 |
| --- | --- |
| 个人资料 | 姓名、用户名、当前邮箱、邮箱验证状态、账号标识 |
| 登录安全 | 修改密码、登录设备、结束某个会话或退出其他设备、身份服务的验证器与授权管理 |
| AI 与地图 Key | DeepSeek、GLM、OpenAI、Claude、其他兼容 AI、高德 Web 服务 Key |
| 记账与云同步 | 坚果云凭据状态、更新与删除，直达 SmartLedger 同步计划与恢复设置 |

修改邮箱和密码会进入身份服务，要求重新验证当前身份，完成后返回个人账号页。换邮箱不会改变账号 subject，因此已有行程、账本与加密凭据归属保持不变。用户名固定，不支持通过资料接口改名。

目前没有配置 SMTP。邮箱可以更换、并用于登录，但新邮箱标记为未验证；不发送验证码或确认邮件。邮件验证及忘记密码仍需另外配置邮件服务。不要将这里的邮箱视为已验证身份。

结束设备会话会撤销该会话的续期能力。已签发的业务访问 JWT 最长可能继续有效至其短期有效期结束（当前约 5 分钟），不能将“结束会话”解释为所有已签发访问令牌即时失效。

## 配置 AI

1. 进入「AI 与地图 Key」，选择服务商。
2. 填写服务商实际提供的 HTTPS API 地址、模型名称和 Key。
3. 选择匹配的协议：Chat Completions、Responses 或 Claude Messages。可在高级选项切换输出 Token 参数或 Claude 的认证头。
4. 勾选「将此 AI 设为当前使用的服务」，点击「加密保存」。其他已保存的个人 AI 配置会保留，但停止作为当前服务。
5. 点击「测试已保存配置」，会发出一条简短请求，可能产生少量服务商费用。

之后旅行 AI 编排会优先使用当前账号启用的配置。没有启用个人 AI 配置时，沿用部署者的默认服务（如果有）。接口协议支持不等于服务商已授权该账号或所填模型可用，模型名需以自己的服务商账号为准。

更换 Key：填写新 Key 并保存。保留 Key：留空，只修改模型等参数。更换服务地址时必须重新输入 Key，避免将已有 Key 意外发送给新的地址。删除配置只删除当前账号的记录。

## 配置高德

填写高德控制台的「Web 服务」Key。服务器用它调用地点搜索，前端不会加载包含该 Key 的 JS SDK。地图选点及公共地图仍可继续使用。高德返回的 GCJ-02 坐标经转换为 WGS84 后进入现有地点数据模型，不能直接当作 WGS84 保存。

Key 的可用性还取决于服务商配额、服务类型及 IP 白名单。当前提供 Key 管理和连接测试；没有有效 Key 时不能声称已完成真实高德账号连通验证。

## 与记账联动

个人账号页通过 SSO 获取独立的记账受众令牌，再访问记账服务原有的坚果云凭据接口。旅游令牌不能直接访问记账 API。

这里和 SmartLedger 使用同一份服务器凭据，任一侧更新或删除会立即反映在另一侧。凭据状态仅显示掩码，更新时重新填写完整账号及应用密码。账本同步频率和账本恢复保留在记账设置中；账号页提供直达入口。

## 存储与接口

- 旅游库新增 `account_provider_credentials`，按当前账号和服务类型保存 AES-256-GCM 密文。每次保存使用新的随机 nonce，附加认证数据绑定 issuer、subject 和 provider。
- 加密密钥从服务器外部文件 `TRAVEL_CREDENTIAL_KEY_FILE` 加载，不写入业务数据库；生产绑定现有 `/run/secrets/credential-keyring.json`。
- Key 不回显、不存入前端 Local Storage，也不写入旅游或账本导出。页面只返回非秘密配置及尾部掩码。传输使用 HTTPS。
- `GET/PUT/DELETE /travel-api/api/v1/account/providers[/服务名]` 仅操作当前账号。`POST .../服务名/test` 测试已保存配置。
- AI 的自定义地址限定公网 HTTPS；底层 HTTP 传输在建立连接时校验并固定 DNS 地址，拒绝内网、回环、链路本地及元数据地址，并禁止跟随重定向。
- 已有账号的自助管理权限在部署时补齐；仅补普通 account 角色，不授予管理其他用户的权限。Keycloak 管理路径仍不对公网开放。

管理员读取服务器文件或控制应用进程时仍可能取得解密能力。凭据加密是静态存储保护，不等于对服务器管理员不可见。
